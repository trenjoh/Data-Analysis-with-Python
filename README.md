# Data Analysis with Python

A comprehensive collection of Jupyter Notebooks covering essential data analysis techniques using Python. This repository serves as a learning resource for mastering data manipulation, cleaning, and visualization with popular Python libraries.

## Project Overview

This project contains practical, hands-on tutorials demonstrating core data analysis skills using industry-standard Python libraries including **Pandas**, **Matplotlib**, and **Seaborn**. Each notebook focuses on specific aspects of the data analysis workflow.

## Repository Contents

### 1. **csv_files_intro.ipynb**
   - Introduction to working with CSV files
   - Loading and exploring CSV data
   - Basic file I/O operations with Python

### 2. **Pandas(csv_data_cleaning).ipynb**
   - Data cleaning fundamentals using Pandas
   - Handling missing values
   - Data validation and transformation
   - Preparing raw data for analysis

### 3. **Data_retrieval_d_frame(pandas)_pynb.ipynb**
   - Comprehensive guide to DataFrame operations
   - Selecting, filtering, and querying data
   - Working with rows and columns
   - Indexing and slicing techniques

### 4. **Analyzing_dt_from_DF(pandas).ipynb**
   - Advanced data analysis with Pandas
   - Statistical analysis and aggregations
   - Grouping and summarization
   - Time-series data handling

### 5. **Plotting_with_pandas_Matplotlib,seaborn.ipynb**
   - Data visualization with Matplotlib and Seaborn
   - Creating various chart types (line, bar, scatter, etc.)
   - Customizing plots and styling
   - Advanced visualization techniques

## Getting Started

### Prerequisites
- Python 3.7+
- Jupyter Notebook or JupyterLab
- Required libraries: Pandas, Matplotlib, Seaborn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/trenjoh/Data-Analysis-with-Python.git
cd Data-Analysis-with-Python
```

2. Install required packages:
```bash
pip install pandas matplotlib seaborn jupyter
```

3. Start Jupyter:
```bash
jupyter notebook
```

4. Open any notebook and start exploring!

## Learning Path

Follow these notebooks in order for a structured learning experience:

1. Start with **csv_files_intro.ipynb** to understand basic file handling
2. Move to **Pandas(csv_data_cleaning).ipynb** for data cleaning skills
3. Explore **Data_retrieval_d_frame(pandas)_pynb.ipynb** for DataFrame operations
4. Advance to **Analyzing_dt_from_DF(pandas).ipynb** for analytical techniques
5. Finish with **Plotting_with_pandas_Matplotlib,seaborn.ipynb** for visualization
